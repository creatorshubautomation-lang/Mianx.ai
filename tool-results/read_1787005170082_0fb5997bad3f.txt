    13→    13→# 1. Purpose
    14→    14→
    15→    15→Mianx.ai is not simply adding a chatbot to business software.
    16→    16→
    17→    17→The goal is an **AI Operating System** in which AI can:
    18→    18→
    19→    19→-   understand business context
    20→    20→-   retrieve authorized knowledge
    21→    21→-   use approved tools
    22→    22→-   execute workflows
    23→    23→-   collaborate with other agents
    24→    24→-   request human approval
    25→    25→-   learn from authorized memory
    26→    26→-   measure its own cost and performance
    27→    27→-   remain inside organization and domain security boundaries
    28→    28→
    29→    29→Architecture:
    30→    30→
    31→    31→``` text
    32→    32→MIANX AI ENGINE
    33→    33→      │
    34→    34→      ├── Model Router
    35→    35→      ├── Agent Registry
    36→    36→      ├── Skill Registry
    37→    37→      ├── Tool Registry
    38→    38→      ├── Context Engine
    39→    39→      ├── Memory Engine
    40→    40→      ├── Knowledge Engine
    41→    41→      ├── Workflow Engine
    42→    42→      ├── Governance Engine
    43→    43→      ├── Evaluation Engine
    44→    44→      └── AI Observability
    45→    45→```
    46→    46→
    47→    47→------------------------------------------------------------------------
    48→    48→
    49→    49→# 2. AI Constitution
    50→    50→
    51→    51→1.  Every agent has an identity.
    52→    52→2.  Every agent has an explicit scope.
    53→    53→3.  Every tool has a declared capability.
    54→    54→4.  AI cannot bypass Core authorization.
    55→    55→5.  Retrieved content is untrusted unless explicitly trusted.
    56→    56→6.  Memory is scoped and governed.
    57→    57→7.  High-risk actions require policy checks and, where configured, human
    58→    58→    approval.
    59→    59→8.  Every meaningful AI action is observable.
    60→    60→9.  AI usage and cost are measurable.
    61→    61→10. Domain AI inherits the same Core AI infrastructure.
    62→    62→
