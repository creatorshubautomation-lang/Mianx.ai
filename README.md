# Mianx.ai — Agentic Software House

> The world's first software house where every client project is delivered by a dedicated team of AI agents. Design, development, content, marketing, QA, and support — all autonomous, all real.

## What is Mianx.ai?

Mianx.ai is a full SaaS platform that runs an entire software house using AI agents. When a client submits a project brief, the system:

1. **Analyzes the brief** using LLM to understand requirements
2. **Assigns the right agent team** from 24 specialized AI agents across 6 teams
3. **Creates a task breakdown** automatically based on the project scope
4. **Starts working immediately** — agents chat with the client, generate deliverables, and update progress in real-time
5. **Delivers production-ready output** — code, designs, content, reports — all quality-checked by QA agents

## 6 Agent Teams · 24 Specialized Agents

| Team | Agents | Specialty |
|------|--------|-----------|
| **Design** | Aria, Kairo, Mira, Nova | Brand strategy, UI design, UX research, graphic design |
| **Development** | Zen, Atlas, Orion, Vega | Frontend, backend, DevOps, database architecture |
| **Content** | Lyra, Sage, Echo, Quill | Copywriting, SEO writing, blog writing, script writing |
| **Marketing** | Flux, Pulse, Spark, Insight | SEO, social media, ad copy, analytics |
| **QA & Review** | Shield, Lens, Cipher, Radar | Testing, code review, security audits, performance |
| **Support** | Halo, Echo2, Triage, Sentry | Chat, email, ticket management, feedback |

Each agent has a specialized system prompt that defines its expertise, tone, and capabilities. All responses are generated by real LLM calls via `z-ai-web-dev-sdk` — no templates, no mock data.

## Tech Stack

- **Framework**: Next.js 16 with App Router
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 4 + shadcn/ui (New York)
- **Database**: Prisma ORM with SQLite
- **Auth**: NextAuth.js v4 (credentials provider, JWT sessions, role-based access)
- **AI**: z-ai-web-dev-sdk (real LLM for chat, analysis, deliverable generation)
- **State**: Zustand (client) + TanStack Query patterns
- **UI**: Framer Motion animations, custom gradient mesh design system
- **i18n**: Custom EN/UR/Roman Urdu translation system

## Database Schema

```
User          → Projects, Messages, Deliverables, Subscriptions, Activities
Agent         → ProjectAgents, Messages (24 agents auto-seeded)
Project       → Client, Agents, Tasks, Messages, Deliverables, Activities
ProjectAgent  → Project + Agent junction (with status & progress)
Task          → Project + assigned Agent
Message       → Project + User/Agent (chat history)
Deliverable   → Project + Uploader (AI-generated files)
Subscription  → User plan tracking
Activity      → Audit trail per project
```

## How AI Agents Work

Every agent interaction is a real LLM call:

1. **Project Brief Analysis** — When a client submits a project, the system sends the brief to the LLM with context about all 24 available agents. The LLM returns a JSON with recommended agents, estimated timeline, and a task breakdown.

2. **Chat Responses** — When a client sends a message in a project chat, the system:
   - Saves the user message
   - Determines the best agent to respond (keyword matching against agent teams)
   - Calls the LLM with that agent's system prompt + project context
   - Saves and returns the agent's response

3. **Deliverable Generation** — When a client requests a deliverable, the system calls the LLM with the agent's system prompt + task description + project context, and saves the generated content (code, design spec, document, etc.) as a downloadable file.

> **Data processing note:** Project titles, descriptions, and chat content are sent to whichever third-party AI provider is active (Z.ai, Gemini, Groq, OpenAI, or Anthropic — see `AI Providers` in `.env.example`) in order to generate responses. If you're deploying this for real clients, disclose this in your privacy policy / terms of service, since project data leaves your infrastructure and is processed by external providers.
